Entry for the make.fun bounty **Invent a Word We Need** — one freshly coined English word with a single-line definition.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```

This writes `entry.txt` (UTF-8, one line) into `$MAKEFUN_OUTPUT_DIR`.

## Entry

The program writes the word and its definition into `entry.txt`. The word names the reflexive "you too" we all catch ourselves saying to a wish that cannot be returned.
